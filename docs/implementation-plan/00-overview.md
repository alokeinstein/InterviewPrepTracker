# Personal Interview Training OS — Overview

## 1. Mission & Product North Star
The **Personal Interview Training OS** is a specialized, production-grade training platform built for a software engineer targeting senior and staff-level roles at top-tier product and engineering companies (Google, Microsoft, Meta, Amazon, etc.).

The central problem it solves:
> **"I am capable of learning, but I procrastinate heavily and have difficulty consistently reading boring technical material and revising things I previously studied."**

The platform transforms passive technical consumption into active, high-retrieval cognitive drills:
$$\text{READ} \longrightarrow \text{UNDERSTAND} \longrightarrow \text{THINK} \longrightarrow \text{PREDICT} \longrightarrow \text{CHECK} \longrightarrow \text{APPLY} \longrightarrow \text{RECALL} \longrightarrow \text{REVISE}$$

## 2. Core Pillars
1. **System Design Academy**: Grounded directly in Martin Kleppmann's *Designing Data-Intensive Applications* (DDIA). No hallucinated chapters; preserves authentic structure, trade-offs, and terminology.
2. **DSA Arena**: Curated 498-question roadmap across 23 dependency-ordered skill levels. Integrated code workspace, multi-language editor, test cases, and a 15-step mental problem-solving framework.
3. **Adaptive Spaced Repetition (SM-2 + Invariants)**: Dynamic revision scheduling based on actual recall performance, mistake tracking, and hint dependency.
4. **Socratic AI Mentor & Interviewer**: Does not spoon-feed code; forces thinking through targeted Socratic questioning, edge case analysis, and simulated 45-60 min mock interviews.
5. **Interactive Architecture Canvas**: Whiteboard with system design components (Clients, CDNs, Load Balancers, API Gateways, Storage engines, Caches, Event Streams) and AI architectural review.
6. **Anti-Procrastination Daily OS**:
   - Zero-friction "START TRAINING" button: generates the optimal next best action.
   - Time-budgeted sessions: 10m, 20m, 30m, 60m.
   - Procrastination Recovery: Welcoming, zero-guilt 7-minute recovery session after inactive days.
   - Deep Focus Mode: Strips all distractions, displays timer, objective, and active drill.
