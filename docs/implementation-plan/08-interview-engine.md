# Interview Engine & Mock Interviews

## 1. Simulated Interview Flows
- **DSA Mock (45 minutes)**:
  - 0–5m: Problem Statement & Clarifications
  - 5–15m: Brute Force & Bottleneck identification
  - 15–35m: Implementation & Dry Run
  - 35–40m: Complexity & Optimization
  - 40–45m: Edge Cases & Follow-up
- **System Design Mock (45–60 minutes)**:
  - Scope & Functional/Non-functional Requirements
  - Capacity Estimations (Throughput, Storage, Bandwidth)
  - API & Data Model Definition
  - High-Level Architecture Diagram
  - Deep-dive into Bottlenecks, Data Stores, Caches, & Fault Tolerance

## 2. Multi-Factor Evaluation Rubric
After each session, the candidate is scored across 5 axes (1–10):
1. **Problem Solving / System Reasoning**
2. **Communication & Structure**
3. **Complexity & Scale Intuition**
4. **Edge Cases & Failure Modes**
5. **Implementation Cleanliness & Confidence**
