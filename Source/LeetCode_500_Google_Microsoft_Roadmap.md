LEETCODE 500 — GOOGLE / MICROSOFT-LEVEL DSA ROADMAP
========================================================

Goal:
Build from fundamentals → core patterns → trees/graphs → DP → advanced algorithms/design.

How to use:
1. Solve in order. Do not jump to Level 20 because a topic looks interesting.
2. For every problem: explain brute force → identify pattern → optimize → code → test edge cases.
3. If you cannot solve a problem, study the solution, close it, and re-code it from memory.
4. Re-solve failed problems after 1 day, 1 week, and 1 month.
5. Do not move to the next level until the current level feels comfortable.

Approximate progression:
Levels 1–4   = fundamentals + core array/string patterns
Levels 5–9   = binary search, linked lists, stacks, intervals, heaps
Levels 10–13 = trees, backtracking, matrices
Levels 14–16 = graphs, DSU, topological sort, greedy
Levels 17–20 = dynamic programming + advanced graphs
Levels 21–23 = advanced extensions, trie/string, design/interval problems

IMPORTANT:
These are the exact LeetCode problem titles intended for copy/paste search.
Some problems are Premium on LeetCode; they are included deliberately because the roadmap is aimed at top-tier interview preparation.
